Privacy
Policy.

A clear description of what ILYRO stores locally, what can leave the device, and how optional Google account features work.

Privacy Policy Terms of Service

Last updated: September 20, 2026

This document describes the privacy behavior of the current ILYRO Browser beta/RC codebase. It should be reviewed again before public store distribution, especially if analytics, advertising, cloud services, account features, or other data flows are added later.

Summary

ILYRO is designed so ordinary browsing data stays on the user's device unless the user explicitly uses a feature that needs a network service, such as visiting a website, using a search engine, signing in with Google, or backing up browser data to Google Drive.

The current ILYRO codebase does not include ILYRO-operated analytics, advertising SDKs, Crashlytics, Sentry, or an ILYRO telemetry backend.

Browsing and website data

Web pages are loaded through Mozilla GeckoView. Websites and services the user visits can receive normal web-request information such as the requested URL, IP address, cookies, headers, browser capabilities, and data the user submits to those sites.

ILYRO stores browser data locally where required for browser functionality, including items such as:

  • browsing history, when history is enabled;
  • bookmarks and quick links;
  • normal-tab session restoration data;
  • browser settings and personalization choices;
  • site permissions and site-specific browser settings;
  • downloads and download state.

Private tabs use a private Gecko session context. Private-page navigation is not added to ILYRO's normal browsing history, and private tabs are intentionally excluded from normal tab-session restoration and ILYRO Drive backup data.

Saved passwords and data transfer

Saved passwords are stored in an application-private vault encrypted with AES-GCM. The encryption key is generated and kept in Android Keystore and is not stored in ILYRO settings or uploaded to ILYRO-operated servers.

ILYRO does not include saved passwords in Google Drive sync. The app disables Android backup and also declares explicit Android 12+ data-extraction rules that exclude application data from cloud backup and device-to-device transfer.

Revealing or editing a saved password requires Android device authentication when a device screen lock is configured. A revealed password is hidden again automatically after a short period.

Password CSV import is processed in memory. ILYRO does not keep a plaintext app copy of an imported CSV. Password CSV export is an explicit user action, requires device authentication, and writes plaintext credentials only to the document location selected by the user. Exported CSV files are not encrypted by ILYRO, so users should store and share them carefully.

Search and address suggestions

When the user performs a search, the query is sent to the search provider selected in ILYRO. If remote search suggestions are enabled/used by the selected provider, suggestion text may be sent to that provider as part of the feature.

Private tabs are designed not to expose local browsing-history suggestions or send remote suggestion queries through ILYRO's omnibox suggestion feature.

Google account and Google Drive sync

Google account features are optional. When the user chooses to sign in and authorize sync, ILYRO can use Google authentication and the Google Drive appDataFolder area to upload and restore an ILYRO browser snapshot.

The current sync snapshot can include:

  • browser settings;
  • browsing history;
  • bookmarks;
  • quick links;
  • normal tab URLs, pin state, group names, and active-tab index.

The current sync format intentionally excludes:

  • passwords;
  • website cookies and authenticated website sessions;
  • private tabs;
  • downloads and downloaded files;
  • Gecko serialized page/session state.

Google's own terms and privacy practices apply to Google authentication and Google Drive services.

Permissions

ILYRO may request Android permissions when a website or browser feature needs them, including camera, microphone, location, notifications, and file/camera access. Site permission prompts are shown by ILYRO/GeckoView before supported website permissions are granted.

Permission choices can also be controlled through Android system settings and ILYRO's site controls where available.

When the user explicitly chooses to open a downloaded APK, ILYRO can ask Android to allow package installation from ILYRO. Package installation is initiated and confirmed by the user; ILYRO does not silently install APK files.

Downloads

Files downloaded through ILYRO are stored on the user's device. Direct and media/HLS downloads can use Android foreground-service notifications so transfer progress remains visible while a download is active.

ILYRO does not upload downloaded files to an ILYRO server.

Content blocking

ILYRO bundles uBlock Origin integration for content blocking. uBlock Origin is a third-party open-source project. Its filter lists and related assets can involve network requests according to uBlock Origin's own behavior and configuration.

Data sharing by ILYRO

The current codebase does not contain an ILYRO-operated advertising network, analytics collector, or telemetry server to which ordinary browsing history is intentionally uploaded.

Network data can still be sent to third parties when the user uses their services, including websites, selected search engines, Google account/Drive services, extension/filter-list infrastructure, and other destinations requested by the user.

Data deletion

Users can clear supported local browser data from ILYRO settings. Android application-data controls can also remove the app's local data. Google Drive sync data can be removed through the account/sync controls when that action is available and authorized.

Changes to this policy

This policy must be updated when ILYRO adds or materially changes data collection, synchronization, analytics, advertising, account, or cloud functionality.

Contact

For privacy questions or support requests, open an issue at GitHub Issues. Do not include passwords, authentication codes, browsing history, or other sensitive personal data in a public issue.

В этом документе описано, как текущая бета-версия/RC-кодовая база ILYRO Browser обрабатывает данные. Перед публикацией в официальном магазине документ следует проверить ещё раз, особенно если позднее появятся аналитика, реклама, облачные сервисы, функции аккаунта или другие способы обработки данных.

Кратко

Обычные данные о просмотре сайтов остаются на устройстве пользователя, если он сам не использует функцию, которой нужен сетевой сервис: например, не открывает сайт, не выполняет поиск, не входит в аккаунт Google или не создаёт резервную копию данных браузера в Google Drive.

В текущем коде ILYRO нет управляемых ILYRO средств аналитики, рекламных SDK, Crashlytics, Sentry или собственного сервера телеметрии.

Просмотр сайтов и данные сайтов

Веб-страницы загружаются через Mozilla GeckoView. Посещаемые пользователем сайты и сервисы могут получать стандартную информацию веб-запроса: запрошенный URL, IP-адрес, cookie, заголовки, сведения о возможностях браузера и данные, которые пользователь отправляет этим сайтам.

Для работы браузера ILYRO хранит на устройстве, среди прочего:

  • историю просмотров, если она включена;
  • закладки и быстрые ссылки;
  • данные для восстановления сессии обычных вкладок;
  • настройки браузера и параметры персонализации;
  • разрешения сайтов и настройки для отдельных сайтов;
  • загрузки и их состояние.

В приватных вкладках используется отдельный приватный контекст Gecko. Посещения страниц в приватном режиме не добавляются в обычную историю ILYRO. Такие вкладки также не восстанавливаются вместе с обычной сессией и не включаются в резервную копию ILYRO в Drive.

Сохранённые пароли и передача данных

Сохранённые пароли находятся в закрытом хранилище приложения, зашифрованном с помощью AES-GCM. Ключ шифрования создаётся и хранится в Android Keystore: он не хранится в настройках ILYRO и не передаётся на серверы ILYRO.

Пароли не включаются в синхронизацию ILYRO с Google Drive. Приложение отключает резервное копирование Android и задаёт отдельные правила извлечения данных для Android 12 и новее, исключающие данные приложения из облачной резервной копии и переноса между устройствами.

Для просмотра или изменения сохранённого пароля требуется аутентификация Android, если на устройстве настроена блокировка экрана. Через короткое время показанный пароль скрывается автоматически.

Импорт CSV-файла с паролями обрабатывается в памяти. ILYRO не сохраняет копию импортированного файла в открытом виде внутри приложения. Экспорт CSV — отдельное действие пользователя, требующее аутентификации устройства; файл с паролями в открытом виде сохраняется только в выбранное пользователем место. ILYRO не шифрует экспортированные CSV-файлы, поэтому храните их и передавайте с осторожностью.

Подсказки для поиска и адресной строки

При поиске запрос отправляется выбранному в ILYRO поисковому сервису. Если выбранный сервис предоставляет удалённые подсказки и эта функция используется, текст запроса может передаваться этому сервису для формирования подсказок.

В приватных вкладках ILYRO не показывает подсказки на основе локальной истории и не отправляет удалённые запросы подсказок через адресную строку.

Аккаунт Google и синхронизация с Google Drive

Функции аккаунта Google необязательны. Если пользователь решит войти и разрешить синхронизацию, ILYRO может использовать аутентификацию Google и папку Google Drive appDataFolder, чтобы сохранить и восстановить копию данных браузера ILYRO.

Текущая копия для синхронизации может включать:

  • настройки браузера;
  • историю просмотров;
  • закладки;
  • быстрые ссылки;
  • URL обычных вкладок, их закреплённое состояние, названия групп и индекс активной вкладки.

В текущий формат синхронизации намеренно не входят:

  • пароли;
  • cookie сайтов и авторизованные сессии на сайтах;
  • приватные вкладки;
  • загрузки и скачанные файлы;
  • сериализованное состояние страниц/сессии Gecko.

Для аутентификации Google и Google Drive действуют собственные условия и правила конфиденциальности Google.

Разрешения

ILYRO может запросить разрешение Android, когда оно нужно сайту или функции браузера: например, доступ к камере, микрофону, геопозиции, уведомлениям или файлам/камере. Перед выдачей поддерживаемых разрешений для сайта ILYRO/GeckoView показывает запрос.

Разрешения также можно настраивать в системных настройках Android и в настройках сайтов ILYRO, если они доступны.

Если пользователь сам выбирает установку скачанного APK, ILYRO может попросить Android разрешить установку приложений из ILYRO. Установку запускает и подтверждает пользователь; ILYRO не устанавливает APK без его участия.

Загрузки

Файлы, скачанные через ILYRO, сохраняются на устройстве пользователя. Для прямых загрузок и медиа/HLS-загрузок могут использоваться уведомления Android foreground service, чтобы показывать ход передачи активного файла.

ILYRO не отправляет скачанные файлы на свой сервер.

Блокировка контента

В ILYRO встроена интеграция uBlock Origin для блокировки контента. uBlock Origin — сторонний проект с открытым исходным кодом. В зависимости от его поведения и настроек списки фильтров и связанные с ними материалы могут загружаться по сети.

Передача данных со стороны ILYRO

В текущей кодовой базе нет управляемых ILYRO рекламной сети, сборщика аналитики или сервера телеметрии, куда намеренно отправлялась бы обычная история просмотров.

Сетевые данные всё же могут передаваться третьим сторонам, когда пользователь использует их сервисы: посещает сайты, пользуется выбранной поисковой системой, сервисами Google Account/Drive, инфраструктурой расширений и списков фильтров или другими запрошенными адресами.

Удаление данных

Пользователь может удалить поддерживаемые локальные данные браузера в настройках ILYRO. Локальные данные приложения также можно удалить в настройках Android. Данные синхронизации в Google Drive можно удалить через настройки аккаунта/синхронизации, если это действие доступно и авторизовано.

Изменения политики

Политику следует обновлять, когда ILYRO добавляет или существенно меняет сбор данных, синхронизацию, аналитику, рекламу, функции аккаунта или облачные функции.

Контакты

По вопросам конфиденциальности или поддержки создайте обращение в разделе GitHub Issues. Не публикуйте в открытом обращении пароли, коды аутентификации, историю просмотров и другие чувствительные персональные данные.
